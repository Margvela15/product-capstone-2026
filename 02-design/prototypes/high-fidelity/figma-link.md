# KIU Nexus High-Fidelity Prototype

Prototype tool: Google Stitch  
Prototype link: https://stitch.withgoogle.com/projects/11165901128751396753

## Prototype Scope

The prototype covers the core KIU Nexus experience for third-year KIU CS students:

1. Nexus Dashboard
2. Course Nerve Centers
3. Automated Inbox
4. Project Group Sync
5. Integration & Bot Management
6. Critical Update Detail

## Design Style

Productive Dark Mode / Academic Terminal

## Core Flow

A student opens KIU Nexus, views all urgent academic updates in one dashboard, checks course-specific deadlines, opens a critical update, and manages integrations with Moodle, Microsoft Teams, and WhatsApp.
