## Screen Flow Snapshot

1. **Weekly Digest**  
   Displays prioritized updates for the next 7 days with source platform badges.
2. **Critical Update Detail**  
   Shows exact requirement, deadline proximity, and required format/action.
3. **Acknowledgement Confirmation**  
   User taps "Acknowledge and Add to Plan" and triggers `critical_update_acknowledged`.
4. **Weekly Plan Board**  
   Consolidates acknowledged items by course and urgency for execution.
